# PushT post-hoc mechanism-analysis note

The aggregate PushT external outcome was known before this mechanism analysis was designed: the preregistered external thresholds failed, with ~1.324x differential amplification.

This analysis therefore cannot supply confirmatory evidence or alter the external pass/fail result. Its sole purpose is explanatory: test whether the attenuated effect is concentrated in counterfactual transitions where the action physically couples to T-block motion.

The plan and analysis script were frozen before any per-sample contact, block-motion, distance-bin, alignment-bin, or subgroup model-error outputs were produced. The script reuses the exact frozen anchor IDs, offsets, architecture, optimizer settings, model seeds, and counterfactual actions. It first requires deterministic reproduction of the original aggregate MSEs before producing subgroup summaries.
